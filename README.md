# Memento Notes

Memento Notes - это легкий локальный сервис для личной базы знаний и заметок. Пользователь запускает приложение на своем компьютере, создает и редактирует заметки через веб-интерфейс, организует их тегами, ищет по заголовкам, содержимому и тегам, а данные хранятся локально в JSON-файле.

Проект использует:

- FastAPI для API-слоя
- Streamlit для локального веб-интерфейса
- pytest для тестов
- uv для управления окружением и зависимостями

## Требования

Жесткие требования для корректного запуска:

- Python `3.12` или новее
- `uv` для создания виртуального окружения и установки зависимостей
- запуск из корня репозитория
- два терминала для полноценной работы: один для FastAPI, второй для Streamlit UI

Проверенные окружения:

- macOS 26.7, Python `3.14.4` - локальная разработка и тесты, а также использование

## Установка

Создайте виртуальное окружение и установите зависимости:

```bash
uv venv
uv pip install -r requirements.txt
```

Создайте локальный файл конфигурации:

```bash
cp .env.example .env
```

Файл `.env` не попадает в git. В репозитории хранится только `.env.example`.

Подробности о настройках и проверке приложения приведены в разделе [«Диагностика»](#диагностика).

## Запуск API

```bash
uv run uvicorn app.main:app --reload
```

Основные маршруты заметок:

- `POST /notes` - создать заметку
- `GET /notes` - получить список заметок
- `GET /notes?tag={tag}` - отфильтровать заметки по тегу
- `GET /notes/search?q={query}` - найти заметки по заголовку, тексту или тегам
- `GET /notes/{note_id}` - получить заметку
- `PUT /notes/{note_id}` - обновить заметку
- `DELETE /notes/{note_id}` - удалить заметку
- `GET /tags` - получить список тегов

## Запуск UI

Streamlit-интерфейс работает как клиент к FastAPI. Сначала запустите API, затем в отдельном терминале запустите UI:

```bash
uv run streamlit run ui/main.py
```

## Диагностика

Все команды выполняются из корня репозитория после установки зависимостей.

### Запуск приложения и /docs

Для обычной работы запустите API без автоматической перезагрузки:

```bash
uv run uvicorn app.main:app
```

API будет доступен по адресу `http://127.0.0.1:8000`. Откройте [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs) в браузере: это интерактивная документация Swagger UI, через которую можно отправлять запросы к API. Для разработки добавьте `--reload`, чтобы сервер перезапускался при изменении кода.

Для работы с заметками через веб-интерфейс запустите во втором терминале:

```bash
uv run streamlit run ui/main.py
```

Откройте адрес, который Streamlit напечатает в терминале (по умолчанию `http://localhost:8501`). Оба процесса должны оставаться запущенными.

### Тесты

```bash
uv run pytest
```

Отдельно проверить служебные маршруты можно командой:

```bash
uv run pytest tests/test_health.py tests/test_version.py
```

Запускать API и UI перед тестами не требуется: тесты API используют `TestClient`, тесты хранилища и операций с заметками работают во временных каталогах, а HTTP-запросы UI-клиента подменяются.

### Переменные окружения

Настройки читаются из `.env` в текущем рабочем каталоге. Непустые переменные окружения процесса имеют приоритет над значениями из файла; если значение не задано, используется значение по умолчанию из таблицы. После изменения настроек перезапустите соответствующий процесс (API и/или UI).

| Переменная | По умолчанию | На что влияет |
| --- | --- | --- |
| `MEMENTO_APP_NAME` | `Memento Notes API` | Название API в `/docs` и поле `app_name` в `/version`. Заголовок Streamlit-интерфейса задаётся отдельно в коде. |
| `MEMENTO_APP_VERSION` | `0.2.0` | Версия в документации API и поле `version` в `/version`. Это метаданные: изменение значения не обновляет код или зависимости. |
| `MEMENTO_LOG_LEVEL` | `INFO` | Минимальный уровень сообщений Python logging для API и JSON-хранилища. `DEBUG` включает более подробные сообщения, если они есть; `INFO` показывает обычные события (запуск, запросы, операции с заметками); `WARNING` оставляет предупреждения и ошибки; `ERROR` — ошибки; `CRITICAL` — только критические ошибки. Сейчас собственные сообщения приложения имеют уровень `INFO`, поэтому `DEBUG` не добавит к ним новых подробностей. Неизвестное название уровня приводит к использованию `INFO`. Логи Uvicorn настраиваются отдельно, например флагом `--log-level debug`; логирование Streamlit этой переменной не настраивается. |
| `MEMENTO_STORAGE_DIR` | `data` | Каталог API для файла `notes.json`. Относительный путь считается от рабочего каталога процесса. Каталог и пустой файл создаются при первом обращении к хранилищу. При смене каталога API читает заметки из нового места; существующие данные автоматически не переносятся. |
| `MEMENTO_API_BASE_URL` | `http://127.0.0.1:8000` | Базовый URL работающего Memento API, к которому обращается процесс Streamlit. Должен содержать схему (`http://` или `https://`), доступный хост и нужный порт, без `/docs` или `/notes` в конце. Изменение этой переменной не меняет адрес или порт запуска Uvicorn. При неверном адресе UI покажет `API is unavailable`. |
| `MEMENTO_ENV_FILE` | `.env` | Путь к файлу настроек вместо стандартного `.env`. Задаётся в окружении процесса (например, `MEMENTO_ENV_FILE=.env.local uv run uvicorn app.main:app`), поскольку используется ещё до чтения файла. Относительный путь считается от рабочего каталога. |

Например, чтобы использовать порт `9000`, запустите API с этим портом:

```bash
uv run uvicorn app.main:app --host 127.0.0.1 --port 9000
```

Укажите в `.env` `MEMENTO_API_BASE_URL=http://127.0.0.1:9000` и перезапустите UI. Для `/docs`, `/health` и `/version` в этом случае тоже используйте порт `9000`.

### Проверка /health и /version

При запущенном API выполните в отдельном терминале:

```bash
curl -i http://127.0.0.1:8000/health
curl -i http://127.0.0.1:8000/version
```

Оба запроса должны вернуть HTTP `200`. Тело ответа `/health` — `{"status":"ok"}`, а `/version` при настройках по умолчанию — `{"app_name":"Memento Notes API","version":"0.2.0"}`. `/health` проверяет доступность API, но не читает JSON-хранилище: успешный ответ сам по себе не подтверждает доступность файла заметок.

### Где смотреть логи

Логи API и Uvicorn выводятся в терминал, где запущен API; сообщения Streamlit — в терминал UI. Приложение автоматически не сохраняет логи в файл. При `MEMENTO_LOG_LEVEL=INFO` запросы `/health` и `/version` сопровождаются сообщениями `Health check requested` и `Version requested`. Собственные логи API содержат время, уровень, имя логгера и сообщение.

Чтобы сохранить вывод API в файл и одновременно видеть его в терминале:

```bash
uv run uvicorn app.main:app 2>&1 | tee memento-api.log
```

## CI

GitHub Actions запускает тесты при `push` и `pull_request`.

После успешных тестов workflow создает artifact `memento-notes-app` с файлами приложения.
